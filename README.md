A round-based tactical first-person shooter in the style of Counter-Strike, built with three.js 0.187.0 for the make.fun bounty "Make the best three.js tactical FPS".

## Gameplay

- Two teams: attackers vs defenders
- Short rounds won by elimination or bomb plant/defuse
- Buy economy between rounds (rifle, SMG, grenade)
- HUD: health, ammunition, round timer, score, money
- Single-player against AI bots
- Original map, art, sounds, and names

## Run locally

```bash
node serve.ts
# open http://localhost:8080
```
